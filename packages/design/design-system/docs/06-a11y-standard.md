# 06 无障碍达标线

版本：1.0.0 ｜ 日期：2026-08-02

DS 组件默认满足下表；应用组装不得破坏这些保证。逐条注明现状（已实现 / 待验）。

| #   | 达标线             | 判据与载体                                                                                                                                                         | 现状                                                |
| --- | ------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------ | --------------------------------------------------- |
| 1   | 对比度 AA          | 色彩意图族的阶型 A/B/C 按对比度定档（不是审美偏好）：600 配白字不达标的族抬到 700，黄色系压到 400 配深字。见 [`04-tokens-contract.md`](./04-tokens-contract.md) §2 | 已实现（token 生成即保证）                          |
| 2   | 焦点环不可清除     | 交互件统一走 `interactive` 配方（focus-visible 环 + 禁用态 + 过渡）；禁止 `outline-none` 而无 `focus-visible` 替代                                                 | 已实现（配方 + lint 双向守）                        |
| 3   | 最小点击目标 40×32 | 小于该尺寸的控件命中区外扩且不占布局（Checkbox 16px 方框外扩到 40×32 的伪元素先例）                                                                                | Checkbox 已实现；其余小控件待验                     |
| 4   | 字号下限 12px      | T2 排版刻度全档最小 12px，字号三档任何档下不破                                                                                                                     | 已实现（刻度即保证）                                |
| 5   | 移动端输入 16px    | 输入框在移动端字号不小于 16px，防 iOS Safari 聚焦缩放                                                                                                              | Input 已实现；其余可输入件待验                      |
| 6   | 状态不只靠颜色     | 语气（tone）带成对图标（toneIcons），状态表达图标 + 文字并行，色盲下语义不丢                                                                                       | 已实现（StatusBadge/Banner 等 tone 件）             |
| 7   | 键盘可达           | Radix 原语自带键盘协议；非 Radix 的自实现交互件须补 Space/Enter 激活与 `preventDefault` 防滚动（ModelBadge 先例）                                                  | Radix 件已实现；自实现件逐件核（ModelBadge 已实现） |

新增组件的验收：逐条对照本表；不满足的先补 DS 能力，不接受应用侧绕过。
